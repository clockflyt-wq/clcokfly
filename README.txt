IMPACT STUDIO WEBSITE
=====================

Files:
- index.html
- style.css
- script.js
- assets/blue-waves-background.png (if included)

HOW TO PREVIEW
1. Keep all files in the same folder.
2. Double-click index.html to open it in your browser.
3. For publishing, upload the folder contents to your web hosting.

CUSTOMIZE BEFORE PUBLISHING
1. Search in index.html for "Impact Studio" and replace it with your brand name.
2. Replace hello@yourstudio.com with your real email address.
3. Replace the illustrative portfolio cards with screenshots of your real projects.
4. Edit service descriptions and contact details to match your business.

NOTES
- The contact button currently opens the visitor's email app (mailto). It does not store form submissions.
- Google Fonts requires an internet connection; fallback fonts are included.
- This is a responsive static website (HTML, CSS and JavaScript), with no build tools required.
